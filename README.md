# emberseed.games — Emberseed 홈페이지

정적 사이트. 빌드 없음. GitHub Pages 가 이 저장소 루트를 그대로 올린다.

- 페이지 다섯 = `index.html`(회사) · `stalveron.html` · `devlog.html` · `spinoff.html` · `contact.html`
- 꾸밈 = `assets/css/site.css` 하나 · 값 하나 = `assets/site.js` 의 `NOTIFY_FORM_URL`(구글 폼/Tally 주소 · 비면 메일 신청)
- 그림 = `assets/img/` (배경·초상은 외주 일러스트 · 로고는 회사 자산 · 원본은 저장소 밖)

## 올리기
1. GitHub → 이 저장소 → Settings → Pages → Source = `Deploy from a branch` · Branch = `main` / `/ (root)`.
2. 도메인을 붙이는 날 = `CNAME` 파일 한 줄(`emberseed.games`) + DNS A/CNAME.
